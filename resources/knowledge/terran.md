# Terran knowledge

Standard multiplayer. `A → B` = A unlocks/requires B; `+` = all requirements. `G/A` = ground/air.

## Tech

```text
SUPPLYDEPOT → BARRACKS → FACTORY → STARPORT → FUSIONCORE
BARRACKS → BUNKER / GHOSTACADEMY
FACTORY → ARMORY
COMMANDCENTER → ENGINEERINGBAY → MISSILETURRET / SENSORTOWER
COMMANDCENTER + BARRACKS → ORBITALCOMMAND (morph)
COMMANDCENTER + ENGINEERINGBAY → PLANETARYFORTRESS (morph)
```

SCV can build COMMANDCENTER, SUPPLYDEPOT and REFINERY without tech prerequisites; REFINERY requires a gas geyser.

## Production and units

```text
COMMANDCENTER / ORBITALCOMMAND / PLANETARYFORTRESS
→ SCV: worker; gather/build/repair

BARRACKS
→ MARINE: cheap general G/A
→ REAPER: fast G scout/harass; cliff jump
+ TECHLAB → MARAUDER: anti-armored G
+ TECHLAB + GHOSTACADEMY → GHOST: G/A caster; EMP/Steady Targeting/cloak/nuke

FACTORY
→ HELLION: fast anti-light G splash
→ WIDOWMINE: burrowed G/A burst/splash
+ ARMORY → HELLIONTANK (Hellbat): durable short-range G splash
+ TECHLAB → SIEGETANK: long-range siege G splash
+ TECHLAB → CYCLONE: mobile G/A; Lock On
+ TECHLAB + ARMORY → THOR: heavy G/A mech

STARPORT
→ VIKINGFIGHTER: anti-air; transforms for G attack
→ MEDIVAC: biological healing + transport
→ LIBERATOR: anti-air splash / siege anti-ground zone
+ TECHLAB → BANSHEE: G-only harass; cloak upgrade
+ TECHLAB → RAVEN: detector/support caster
+ TECHLAB + FUSIONCORE → BATTLECRUISER: heavy G/A; Tactical Jump; Yamato upgrade
```

## Essentials

- TECHLAB: advanced units + producer-specific research. REACTOR: 2 slots for non-Tech-Lab units. BARRACKS/FACTORY/STARPORT use one attached add-on and may swap add-ons.
- ENGINEERINGBAY: infantry/structure upgrades. ARMORY: vehicle/ship upgrades and infantry L2–3 prerequisite. GHOSTACADEMY: Ghost/nuke tech. FUSIONCORE: advanced air tech.
- SUPPLYDEPOT: supply; raise/lower. ORBITALCOMMAND: MULE/Scan/Extra Supplies. PLANETARYFORTRESS: ground defense. BUNKER: infantry garrison. MISSILETURRET: anti-air + detector. SENSORTOWER: radar only.
- COMMANDCENTER/ORBITALCOMMAND/BARRACKS/FACTORY/STARPORT can lift; PLANETARYFORTRESS cannot. Lifted production buildings cannot produce.
- RAVEN/MISSILETURRET detect cloaked/burrowed units; Scanner Sweep temporarily provides vision + detection.
