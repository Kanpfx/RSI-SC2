# Terran knowledge (SC2 LotV / python-sc2)

`→` = prerequisite (Buildings), trains (Units), researches (Research); `+` = all required; `/` = either. Add-ons must be attached. Research levels require the preceding level.

## Buildings

```text
SUPPLYDEPOT → BARRACKS → FACTORY → STARPORT → FUSIONCORE
BARRACKS → BUNKER, GHOSTACADEMY
FACTORY → ARMORY
COMMANDCENTER → ENGINEERINGBAY → MISSILETURRET, SENSORTOWER
COMMANDCENTER + BARRACKS → ORBITALCOMMAND (morph)
COMMANDCENTER + ENGINEERINGBAY → PLANETARYFORTRESS (morph)
BARRACKS → BARRACKSTECHLAB / BARRACKSREACTOR
FACTORY → FACTORYTECHLAB / FACTORYREACTOR
STARPORT → STARPORTTECHLAB / STARPORTREACTOR
```

SCV builds COMMANDCENTER, SUPPLYDEPOT, REFINERY without tech prerequisites.
