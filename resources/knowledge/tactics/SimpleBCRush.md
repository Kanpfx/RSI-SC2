# Overview

**Strategy Name:** Simple BC Rush

**Core Idea:** Rush BATTLECRUISER technology, use the first BATTLECRUISER to jump into the enemy mineral line, then mass 3–4 BATTLECRUISER units for a final assault.

**General Rules:**
- Prioritize technology; minimize military production before the first BATTLECRUISER.
- Maintain gas income and build SUPPLYDEPOT to avoid supply blocks.
- Treat timings as guidelines; prioritize defense against early attacks.
- Preserve BATTLECRUISER units. Retreat and repair damaged ones with SCV.

# Stages

## Stage 1: Opening and Tech Rush

**Enter When:** Game starts.

**Stage Guidance:**
- **0:00–1:30:** Build SUPPLYDEPOT → REFINERY → BARRACKS → FACTORY, upgrade to ORBITALCOMMAND, then build a second REFINERY.
- **1:30–2:30:** Build STARPORT and another SUPPLYDEPOT.
- **2:30–3:30:** Build FUSIONCORE → STARPORTTECHLAB, then immediately start the first BATTLECRUISER.
- Pause SCV production if necessary to prioritize technology.

## Stage 2: First BC Strike

**Enter When:** The first BATTLECRUISER starts production.

**Stage Guidance:**
- **3:30–4:30:** Build SUPPLYDEPOT → second COMMANDCENTER → SUPPLYDEPOT, and resume SCV production.
- **4:30–5:30:** Once the first BATTLECRUISER is ready, use EFFECT_TACTICALJUMP to attack the enemy main mineral line. Prioritize SCV / DRONE / PROBE.
- Retreat from heavy anti-air fire and repair with SCV.

## Stage 3: Mass BC Assault

**Enter When:** The first BATTLECRUISER completes its initial strike.

**Stage Guidance:**
- Continuously produce BATTLECRUISER while adding SCV, SUPPLYDEPOT, and REFINERY. Add more STARPORT with STARPORTTECHLAB when affordable.
- Gather 3–4 BATTLECRUISER units and use EFFECT_TACTICALJUMP to launch a coordinated assault on the enemy main base.
- Prioritize SCV / DRONE / PROBE. Eliminate dangerous anti-air units before destroying production structures and the main base.
- Keep producing BATTLECRUISER reinforcements until victory.
